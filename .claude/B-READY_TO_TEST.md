## 🎯 If Something Breaks

**Common issues and fixes:**

### `firebase_options.dart` not found
```
Error: Could not find a file named "firebase_options.dart"
```
**Fix:** A forgot to run `flutterfire configure` or didn't commit it.
- Post in Discord: "@A, I don't see firebase_options.dart. Did you run `flutterfire configure`?"

### Firestore not enabled
```
Error: Cloud Firestore not enabled
```
**Fix:** A needs to enable Firestore in Firebase console
- Post in Discord: "@A, can you enable Firestore in the Firebase console?"

### geolocator permission errors
```
Error: Location permission denied
```
**Fix:** On web, geolocator may not work. Check Flutter Chrome docs for emulation.
- For now, hardcode a test location in request_form.dart

### Cloud Function deployment fails
```
Error: Must upgrade to Blaze plan
```
**Fix:** Spark plan can't run Functions. Ask A to upgrade or use emulator.
- For hackathon: use local `firebase emulators:start --only functions,firestore`
